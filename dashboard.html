NORTHSTREAM Service Dashboard

NORTHSTREAM simulates a real-time, governed, AI-ready data platform end to end — CDC, event streaming, lakehouse, governance and local AI chat with data — using only open-source components. This page links every UI in the stack so you don't have to remember ports during a demo or workshop.
